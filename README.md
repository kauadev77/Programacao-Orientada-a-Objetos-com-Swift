# Programação Orientada a Objetos com Swift

Ambiente preparado em **Swift** para atividades do programa **Foundation iOS / TIC em Trilhas**, com suporte a GitHub Codespaces e Swift Package Manager.

## Objetivo

Facilitar a execução das atividades do curso sem exigir configuração manual de uma IDE local, permitindo que os exercícios sejam desenvolvidos diretamente em um ambiente reproduzível.

## Tecnologias

- Swift
- Swift Package Manager
- GitHub Codespaces
- Dev Containers
- Visual Studio Code

## Estrutura

```text
.
├── .devcontainer/
├── .vscode/
├── Sources/
├── Package.swift
└── README.md
```

## Uso

O repositório pode ser aberto em um Codespace para iniciar rapidamente um ambiente Swift configurado para as atividades da trilha.
